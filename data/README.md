# LTAC low-visibility data set (data card)

Ankara Esenboğa International Airport (ICAO **LTAC**, WMO 17128; 40.128° N, 32.995° E,
953 m AMSL), January 2005 – October 2026.

## Contents

| Path | Description |
|---|---|
| `raw/metar/LTAC_IEM_<year>.csv.gz` | Original METAR/SPECI text from the Iowa Environmental Mesonet (IEM) ASOS archive. Records tagged `IEM_DS3505` are reconstructions from NCEI ISD and are **excluded** by the pipeline. |
| `raw/metar/LTAC_OGIMET_<yyyy-mm>.csv.gz` | Original METAR/SPECI text from Ogimet (`getmetar`), used to fill IEM gaps 2005–2012. |
| `raw/taf/LTAC_TAF_*.txt` | Official TAFs (Ogimet monthly dumps and/or the 30-day NOAA AWC archive), one TAF per stamped line. |
| `processed/features.parquet` | 77 predictors on the 30-min analysis grid (HH:20/HH:50 UTC). |
| `processed/targets.parquet` | Targets for lead times 1–6 h: `y_fog_<h>h` (VIS < 1000 m), `y_rvr_<h>h` (0: RVR ≥ 550 m, 1: 350–550 m, 2: < 350 m), `vis_<h>h`. |

`data/interim/reports_decoded.parquet` (one row per decoded report) and `processed/grid.parquet`
are regenerated by `scripts/01_prepare_data.py`.

## Processing summary

1. Merge sources (IEM preferred), drop NIL / malformed reports, decode with `src/esenboga/metar.py`.
2. Quality control: physical range checks, dew point ≤ temperature + 0.5 °C, isolated-spike removal
   for T, Td and QNH (see `results/tables/qc_log.json`).
3. Regular 30-min grid: the state at time *t* is the latest report issued in (*t* − 29 min, *t*];
   no interpolation – missing slots stay missing.
4. Targets at *t* + *h* use the same rule, so a target never re-uses the observation at *t*.

## Definitions

* **Fog / low visibility**: prevailing visibility < 1000 m (ICAO/WMO fog threshold).
* **RVR class**: minimum RVR over all reported runways; when VIS ≥ 1500 m (RVR not required)
  the class is CAT I+; if RVR is missing while VIS < 1500 m (0.1 % of cases) the prevailing
  visibility is used as a conservative proxy.
